# Data Model: Dashboard Content E2E Suite

## Entities & Test Shapes

### Test Context Marker
- `runId`: String (e.g. `e2e-1728150000-abcd`)
- `token`: JWT access token acquired during auth setup

### Test Project
- `title`: `E2E Project [runId]`
- `slug`: `e2e-project-[runId]`
- `category`: `Commercial` or existing category ID/slug
- `status`: `Completed`
- `location`: `Cairo, Egypt`
- `coverImage`: URL or uploaded asset path
- `overview`: `E2E project overview description`
- `challenge`: `E2E project challenge`
- `solution`: `E2E project solution`
- `result`: `E2E project result`

### Test Service
- `title`: `E2E Service [runId]`
- `tagline`: `E2E Service Tagline`
- `description`: `Detailed description for E2E service`
- `features`: `["Feature A", "Feature B"]`
- `icon`: `Building`

### Test Page Content Section
- `page`: `contact`
- `section`: `hero`
- `content`: Object with `title`, `subtitle`, etc.
- `originalContent`: Stored prior to modification to enable exact restoration

### Test Job Position
- `title`: `E2E Engineer [runId]`
- `location`: `Cairo, Egypt`
- `type`: `Full-time`
- `description`: `E2E job position description`
- `requirements`: `["Req 1", "Req 2"]`
- `isActive`: Boolean (`true` or `false`)

### Test Contact Message
- `name`: `E2E Tester [runId]`
- `email`: `e2e-[runId]@example.com`
- `phone`: `+201000000000`
- `subject`: `E2E Inquiries`
- `message`: `This is a test message generated by E2E run [runId]`
